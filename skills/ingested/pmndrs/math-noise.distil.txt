# Math Noise and Seeded Random
- DO: create a seeded generator once with mulberry32.create(seed) (math/random) and draw numbers in [0, 1) from it with mulberry32.sample(state).
  source: "`mulberry32.sample(state: Mulberry32): number` — Advances `state` and returns the next number in the range [0, 1)."
- WHEN a helper takes a RandomGenerator (random.float, random.int, random.choice): pass it a function that returns a number in [0, 1), such as () => mulberry32.sample(state).
  source: "`type RandomGenerator = () => number` — A function that returns a random number in the range [0, 1)."
- DO: create each noise generator once from a seed with simplex2d.create(seed) (or perlin2d, worley2d) and sample it per point with simplex2d.sample(gen, x, y), which returns a value in [-1, 1].
  source: "`simplex2d.sample({ perm, grad3 }: Simplex2DGenerator, x: number, y: number): number` — Samples 2D simplex noise, returning a value in the interval [-1, 1]."
- WHEN layering octaves for terrain: call fbm(sample, octaves, lacunarity, gain) with a sample function of the frequency; ridged and billow take the same arguments.

- DO: import generators from math/random and noise from math/noise, as in import { mulberry32 } from 'math/random'.
  source: "import { mulberry32 } from 'math/random';"
