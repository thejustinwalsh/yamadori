```python
import sys

def main():
    data = sys.stdin.read().split()
    N = int(data[0])
    S = data[1]

    positions = [i for i, c in enumerate(S) if c == '1']
    K = len(positions)

    # a_i = p_i - i ; answer = sum |a_i - t| minimized at median t
    a = [positions[i] - i for i in range(K)]
    t = a[K // 2]
    if t < 0:
        t = 0
    elif t > N - K:
        t = N - K

    ans = sum(abs(ai - t) for ai in a)
    print(ans)

if __name__ == "__main__":
    main()
```

**Explanation of the approach:**

1. **Preservation of order:** Adjacent swaps of identical `1`s never change their relative ordering, so the i-th `1` (at position `p_i`) must end up at the i-th position of the final contiguous block.

2. **Target block:** If the final contiguous block of `K` ones starts at position `t`, then the i-th `1` must move from `p_i` to `t + i`. The minimum number of adjacent swaps is `sum |p_i - (t + i)| = sum |(p_i - i) - t|`.

3. **Minimizing over t:** Let `a_i = p_i - i`. We need `sum |a_i - t|`, which is minimized when `t` is the **median** of the array `a`. Since `a` is non-decreasing, `t = a[K // 2]` is the median. (It is always within the valid range `[0, N-K]`, but I clamp for safety.)

4. **Complexity:** O(N) time and O(K) space, well within the limit for N up to 5·10⁵.
